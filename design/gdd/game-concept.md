## 1. 一句话定位

**"七大洲站起来，七个动物文明开打。"**

8 分钟一局、按七大洲分 7 阵营的卡通 2.5D 4X 回合制手游，主打**动物抽卡 + 镜像攻击异步 PvP + 阵营同盟**。

---

## 2. 七大洲阵营与旗舰动物

按"七大洲 7 阵营"原则，每个阵营锁定一个旗舰动物：

| # | 阵营 | 旗舰动物 | 调性关键词 |
|---|---|---|---|
| 1 | 亚洲 | 大熊猫 | 竹林 / 禅意 |
| 2 | 欧洲 | 灰狼 | 群猎 / 协作 |
| 3 | 非洲 | 非洲狮 | 草原 / 强权 |
| 4 | 北美 | 灰熊 | 山脉 / 孤独 |
| 5 | 南美 | 美金刚鹦鹉 | 雨林 / 色彩 |
| 6 | 大洋洲 | 袋鼠 | 沙漠 / 速度 |
| 7 | 南极 | 帝企鹅 | 冰原 / 群居 |

### 2.1 南极阵营处理

保留作为"南极冰下议会"——企鹅群居本就自带"议会"叙事,不追求生态学严谨。
**机制上南极与其他 6 阵营完全对称**(同种 PvP / 抽卡权重)。

## 3. 核心循环（8 分钟一局）

```
匹配 / 闯关（30s）
  → 选择阵营与指挥官（10s）
  → 回合制宏观 [探索 / 建造 / 研究 / 招募] 5–6 回合（每回合 ~60s，共 5min）
  → 期间可能触发"前线冲突" → 切入"前置编队"短关（5–10s 下达命令，AI 自动执行）
  → 回合结束 / 胜利条件（剩余 ~2min 结局动画）
  → 结算：经验 / 阵营声望 / 抽卡券 / 奖励卡 → 调整牌组 → 下一局
```

**异步 PvP 注入点**：玩家在 PvE 闯关模式打出来的"通关时刻布阵" → 自动保存 →
系统喂给最近活跃的对手玩家 → 反手布阵 → 双方各自上线看到战报。

---

## 4. 差异化卖点

1. **"七大洲动物文明"IP 锚点** —— 收集 7 阵营 × 多动物 = 收藏驱动
2. **"前置编队 + 半即时战术"** —— 避免纯回合、避免 PC 级 RTS，命中手游碎片化
3. **镜像攻击异步 PvP** —— 不同步匹配、不吃流量、有社交痕迹
4. **卡通 2.5D 美术反差** —— 策略 + 萌，避开重度 3D 写实竞品

---

## 5. 目标用户

- **25–40 岁怀旧策略玩家** —— 曾在 PC 端玩过文明 6 / 火纹 / 红警，但现在没时间拼长剧本
- 同时玩《率土之滨》《部落冲突》类中度策略手游
- 接受 Gacha 抽卡（与日式策略手游心智重叠） + 社交炫耀（X.com / 微信群分享）

---

## 6. PvP 设计：镜像攻击 + 公平竞技约束

### 6.1 风险提示

Gacha + 镜像攻击 PvP 同时启用，玩家会遭遇"我充了 1 万他充了 10 万"的强度差 →
镜像被高 R 碾压 → 流失。

### 6.2 对策（必须配套）

| 机制 | 说明 |
|---|---|
| **镜像池只取 PvP 准入英雄** | 镜像攻击里只能用"通用英雄池"中的动物，与 Gacha 高 R 解锁的英雄分开 |
| **PvP 段位独立** | PvP 用 ELO 分段，玩家匹配同段位镜像对手，避免等级压制 |
| **Gacha 英雄仅在 PvE 闯关中加成** | 高 R 玩家在 PvE 更快过图，但 PvP 中无差异 |
| **战斗节奏 8 分钟，硬性** | 防止高 R 玩家用"拖时间"羞辱低 R 玩家 |

## 7. 社交系统

- ✓ **镜像攻击 PvP**（必选）
- ✓ **阵营同盟 / 国联**（已选）
- ✗ 朋友圈/战报分享（暂未启用，留 v1.x 增量）
- ✗ 师徒 / 微信群分享（暂未启用，留 v2.x 增量）

### 7.1 阵营同盟机制

同阵营 4–6 人组成国联，联服打世界 BOSS（如"巨象 / 海怪"），按总伤 / 累计分赛季奖励。
**新手引导期** 强制加入或自动匹配一个**入门级国联**（3 AI 替代 + 1 真人）。

---

## 8. 美术风格

- **卡通 2.5D**：3D 模型 + 烘焙卡通描边 + 平面投影
- 7 阵营各 1 旗舰 + 4–6 普通动物 = 共 35–49 个基础角色
- UI 用低饱和度配色（区别于重度策略游戏的黑灰），主色随阵营变
- 动作风格：略夸张的卡通动作 + 表情动画（3–5 帧关键帧）

---

## 9. 变现模式：动物抽卡（Gacha）

**主收入来源**：动物英雄抽卡。池子分：
- **常驻池**（6 阵营各 1 个 SSR 旗舰动物）+ **限定池**（每赛季 1 个特殊阵营）
- **抽卡保底** 90 抽 SSR，300 抽大保底（行业标准）
- **抽卡券** 通过 PvE / 镜像攻击战报 / 日常任务发放（玩家日常白嫖量充足）

**配套非付费来源**：
- 赛季通行证（保留为 v1.x 增量）
- 阵营皮肤 / 表情包 / 头像（小规模补充）

**公平竞技约束** 详见 §6 —— 必须严格区分 PvE / PvP 英雄池。

## 11. 风险 / 待决项

| 风险 | 应对 |
|---|---|
| Gacha + PvP 平衡崩坏（高 R 碾压） | §6 公平竞技约束 + §10 强制技术实现 |
| 镜像攻击对手匹配延迟（在线玩家少时） | 引入"AI 镜像"（PvE 难度 +50% 的 NPC 镜像）兜底 |
| 8 分钟一局，CPU/内存压力（iOS 低端机） | Unity 6 LTS 性能预算：120 MB 包体 / 30 fps / 1 GB RAM |
| 国联聊天合规（未成年人保护） | 国联启用聊天过滤 + 限时窗口 |
| 美术成本：35–49 个基础角色 + 7 阵营皮肤 | 第一版只做 4 阵营 PvE（亚洲/欧洲/非洲/南美），其余 3 阵营 v0.5 增量 |
| 单周原型验证 1 阵营 1 地图 8 分钟循环 | 已立项，作为 v1.1.1 关键路径 |
