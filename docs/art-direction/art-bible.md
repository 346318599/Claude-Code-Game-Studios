## 1. 全球美术原则

### 1.1 卡通 2.5D 定义

| 维度         | 规范                                                |
| ---------- | ------------------------------------------------- |
| **模型维度**   | 3D 低多边形（low-poly）网格 + 平面纹理投影                   |
| **描边**     | NPR（Non-Photorealistic Rendering）反向描边，2px 黑色等宽    |
| **光照**     | Toon Shading（cel-shading），2 阶明暗，无渐变             |
| **投影**     | 平面硬边阴影，禁止软投影                                   |
| **材质**     | 无 PBR，色块 + 描边代替细节，色块边缘锐利                       |
| **贴图**     | 手绘纹理 + 程序化贴图，**禁止**照片拼贴                         |

### 1.2 风格三原则

1. **"萌而不幼"** —— 角色拟人化（直立、有表情、可对话），**不幼态化**（眼睛不放大、不 Q 版化）。
2. **"夸张而克制"** —— 动作幅度可夸张（参考 Disney / Pixar 早期），但材质表现克制（色块为主）。
3. **"地域可识别"** —— 7 阵营配色 + 角色外形要 3 秒内可辨识。

### 1.3 风格禁忌（必须避免）

| ✗ 禁忌                       | 理由                            |
| --------------------------- | ----------------------------- |
| 写实 3D 渲染                   | 与卡通调性冲突，且移动端性能差              |
| 纯像素（16-bit 以下）            | 与"动物文明"IP 重量感冲突             |
| 幼态化 Q 版                   | 与 25–40 岁目标用户审美不符            |
| 过度拟人（穿西装打领带）             | 破坏"动物"主题的轻盈感               |
| 色情化（如过凸的胸 / 臀）            | 合规风险 + 调性失衡                 |
| 暴力血腥（断肢 / 流血）             | 合规风险 + 卡通调性冲突               |
| 真实动物照片                    | 风格不统一                        |

### 配色规则

- UI 主背景统一 `#1A1F2E` 暗夜蓝（7 阵营共用）。
- 阵营色仅用于：阵营选择按钮 / 角色名称 / BUFF 图标边框 / 棋盘格阵营归属。
- 战斗单位颜色 ≠ UI 颜色（避免视觉混淆）。

## 3. 角色设计规范

### 3.1 拟人化比例

参考动物原种 + 拟人化身高：

| 阵营            | 角色身高比例（头身比） | 体型关键字   |
| ------------- | ------------ | -------- |
| 亚洲（大熊猫）       | 4 头身         | 圆润、稳重   |
| 欧洲（灰狼）        | 5 头身         | 修长、敏捷   |
| 非洲（非洲狮）       | 5.5 头身       | 健壮、领袖   |
| 北美（灰熊）        | 5 头身         | 厚实、力量   |
| 南美（美金刚鹦鹉）     | 3.5 头身       | 小巧、灵活   |
| 大洋洲（袋鼠）       | 5 头身         | 跳跃、爆发   |
| 南极（帝企鹅）       | 4 头身         | 群居、憨厚   |

### 3.2 表情集（每角色必备 8 表情）

- IDLE（待机）/ HAPPY / SAD / ANGRY / SURPRISE / FEAR / PAIN / WIN

每个表情 3 帧关键帧，引擎内可循环或触发。

### 3.3 动作风格

| 动作类型 | 帧数       | 风格                                |
| ---- | -------- | --------------------------------- |
| 待机呼吸 | 1 帧循环    | 微微起伏                              |
| 行走   | 8 帧循环    | 略夸张步幅，参考《动物狂想曲》                    |
| 攻击   | 5 帧关键帧   | 弹性预备 + 爆发 + 收招                     |
| 受伤   | 3 帧关键帧   | 击退 + 表情切换 + 复位                     |
| 死亡   | 5 帧关键帧   | 慢动作 + 旋飞 + 落地                      |
| 胜利   | 6 帧关键帧   | 跳跃 + 张臂 + 定格                       |

### 3.4 3D 模型技术规格

- 多边形预算：**单角色 ≤ 3000 tris**（含描边）。
- 骨骼数：≤ 30（Humanoid 兼容）。
- 贴图：**单角色 1 张 1024×1024 atlas**（4 套表情 + 6 套动作合并打包）。
- 描边：边缘 Shader 后处理，**禁止**模型内建描边网格（影响 batching）。

## 4. UI 设计规范

### 4.1 全局 UI 原则

- 暗色基底 + 阵营色高亮（对比度 WCAG AA）。
- 字体：中文 / 简中 / 日韩 / 英文按地区分流（详见国际化 §）。
- 图标：**单色描边 + 阵营色填充**，禁止写实图标。
- 按钮：**圆角矩形 8px**，长按 / 短按双状态。
- 触屏友好：**最小可点击区 44×44pt**。

### 4.2 布局约束

- 顶部固定：玩家头像 / 阵营 / 资源条（高度 56pt）。
- 底部固定：功能按钮栏（4 个主功能 + 设置）。
- 中部动态：游戏主视图（棋盘 / 编队 / 抽卡）。
- 弹窗层级：Toast（3s 自动消失）/ Dialog（模态阻塞）/ FullScreen（带遮栏）。

### 4.3 阵营主题切换

每个阵营的 UI 主题包：

- 主题色（4 色，详见 §2）。
- 阵营图标（4 帧循环）。
- 阵营 BGM（详见音效规范）。
- 阵营 Logo 动效（6 帧入场）。

## 5. 动画规范

- 帧率：30 FPS（移动端默认），60 FPS（iPhone 12+ 可选）。
- 关键帧：3–5 帧。
- 缓动函数：BackEase / ElasticEase（战斗动作），CubicEase（UI 过渡）。
- 状态机：Animator Controller（Humanoid 兼容）。

## 6. 镜头 / VFX 规范

### 6.1 镜头

- **主镜头**：等距 30° 俯视（参考 Civilization / XCOM）。
- **战斗特写**：45° 前俯，平滑过渡 0.5s。
- **抽卡演出**：正面平视 + 旋转（3 圈 / 1.5s）。
- **PvP 战报回放**：固定机位 + 时间轴拖动。

### 6.2 VFX

- **阵营 BUFF**：阵营色光晕（呼吸循环 1s）。
- **伤害数字**：白底 + 黑描边（避免混淆），浮空 0.5s。
- **抽卡稀有度**：
  - R（普通）：白闪
  - SR（稀有）：蓝闪
  - SSR（超稀有）：金闪 + 全屏震动 0.2s + 阵营色光柱

## 7. 音效设计原则

| 类型     | 风格                                                       |
| ------ | -------------------------------------------------------- |
| 战斗音效   | 卡通化打击 + 阵营音色调制（如大熊猫 = 木鱼节奏，灰狼 = 鼓声）                     |
| UI 音效  | 短促清脆（≤ 0.2s），**禁止**长音效                                    |
| 阵营 BGM | 主旋律 + 阵营音色调制（非洲 = 鼓点，亚洲 = 笛子，企鹅 = 合成器）                   |
| 抽卡音效   | SSR 三段式（蓄力 → 爆发 → 余韵）                                      |

## 9. 美术外包规范

### 9.1 文件命名

```
factions/
  asia/
    characters/
      panda_panda_ssr/
        model.fbx        # 3D 模型
        texture.png      # 1 张 atlas 1024×1024
        animation.fbx    # 含 6 套动作
        preview.png      # 立绘预览
```

### 9.2 验收标准

- 模型 tris ≤ 3000。
- atlas 贴图 ≤ 1024×1024（PNG，含 alpha）。
- 动画 fbx 帧数符合 §3.3。
- preview 立绘分辨率 2048×2048。

### 9.3 提交格式

- 提交人 / 日期 / 版本号 / 修改日志。
- 单个角色不超过 50 MB。
- 通过 Git LFS 提交（见 tech-setup §6）。
